# INFOMADS-2026

Program for project of algorithms for decision support (INFOMADS) 2026

# How to run

The algorithm can be run by simply running `python solver.py` in the terminal, from the folder this README is located in.

# Input and output

The python file loads the instance from "offline test instances.txt" and writes the output in a file called "offline test results.txt".

# Necessary packages

The following packages are needed: numpy, scipy. These can be installed with `pip install numpy` and `pip install scipy`, assuming you have pip installed
